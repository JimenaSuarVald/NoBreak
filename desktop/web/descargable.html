DESCARGAS

Obtén la versión de escritorio de No Break para una experiencia sin interrupciones. Incluye su propio runtime de Java, no necesitas instalar nada más.

Descargar para Windows (.zip)

Tamaño aprox. 52 MB · Windows 10/11 64-bit

Pasos:

  1. Descarga el archivo NoBreak-windows.zip.
  2. Haz click derecho → Extraer todo… en la carpeta que prefieras.
  3. Entra en la carpeta NoBreak y ejecuta NoBreak.exe.
  4. La primera vez puede que Windows muestre un aviso de SmartScreen porque el ejecutable no está firmado; pulsa Más información → Ejecutar de todos modos.
  5. Al primer arranque crea una cuenta con usuario y contraseña, y elige la carpeta donde tienes tu música. El reproductor escaneará esa carpeta y todas sus subcarpetas.
  6. Vuelve a la web, abre el menú principal e inicia sesión con las mismas credenciales para escuchar tu biblioteca desde el navegador.

Puedes cambiar la carpeta o forzar una actualización en cualquier momento desde el menú Biblioteca de la app de escritorio. La biblioteca también se actualiza sola al añadir o quitar archivos mientras la app está abierta.
